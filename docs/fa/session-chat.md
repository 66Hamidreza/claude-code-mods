# پیام‌رسانی میان نشست‌ها

session-chat نشست‌های Claude Code روی همان دستگاه و همان پوشهٔ خانه را پیدا می‌کند و یک صندوق پیام کوچک بالای ورودی می‌گذارد. همهٔ نشست‌های مقصد باید افزونه را بارگذاری کرده باشند.

## فرمان‌ها و نمونه

| فرمان | کارکرد |
| --- | --- |
| `/who` | تازه‌سازی و نمایش نشست‌ها |
| `/msg <target> <text>` | ارسال به یک نشست |
| `/all <text>` | ارسال همگانی به نشست‌های پیدا‌شده |
| `/chat` | باز و بسته کردن نوار و صفر کردن شمارندهٔ خوانده‌نشده |
| `/chat name <name>` | تغییر نام؛ فاصله‌ها به خط تیره تبدیل می‌شوند |

مقصد ابتدا با نام دقیق، سپس پیشوند شناسهٔ نشست و بعد پیشوند یکتای نام تطبیق داده می‌شود.

</div>

```text
/chat name parser
/who
/msg worker Please avoid editing parse.ts while I finish.
```

<div dir="rtl">

مدل به ابزارهای `mcp__session-chat__peers` و `mcp__session-chat__broadcast` دسترسی می‌گیرد و یک یادداشت هماهنگی دریافت می‌کند. برای پیام مستقیم نیز می‌تواند از SendMessage میزبان استفاده کند.

## تنظیمات و روش کار

متغیر محیطی اختصاصی ندارد؛ HOME مسیر `~/.claude/mods-data/session-chat/peers` را تعیین می‌کند. نام پیش‌فرض از پوشهٔ کاری و چهار نویسهٔ اول شناسه ساخته می‌شود. نام ذخیره‌شده برای همان نشست دوباره استفاده می‌شود.

هر ۱۰ ثانیه یک رکورد حضور نوشته می‌شود؛ رکوردهای قدیمی‌تر از ۴۵ ثانیه حذف از نمایش می‌شوند. پایان نشست، رکورد را غیرفعال می‌کند. پیام‌ها برچسبی مانند `[chat:parser]` دارند. حداکثر ۱۰۰ پیام نگهداری و سه پیام آخر در نوار نمایش داده می‌شود.

## محدودیت‌ها

این سامانه سرور گفت‌وگوی شبکه‌ای نیست. تحویل به فعال بودن مقصد و رابط میزبان بستگی دارد و فهرست ممکن است با تأخیر به‌روز شود. فایل‌های حضور شامل مسیر کاری و شناسهٔ نشست هستند. برای بازخوانی درست برچسب پیام، نام کوتاه و بدون فاصله یا ] انتخاب کنید. برخورد نام فرمان با فرمان داخلی گزارش می‌شود و ثبت بقیهٔ فرمان‌ها ادامه پیدا می‌کند.
