# مشارکت

گزارش باگ، اصلاح مستندات و تغییر کوچک با محدودهٔ روشن پذیرفته می‌شود. قواعد AGENTS.md مرتبط و مشخصات کار را رعایت کنید. اگر قواعد مخزن گیت را برای عامل منع کرده‌اند، اجرای گیت را به نگه‌دارنده یا wrapper مجاز بسپارید.

## روند کار

۱. رفتار فعلی و مورد انتظار را با نمونهٔ حداقلی شرح دهید؛ اطلاعات محرمانه و مسیرهای شخصی را حذف کنید.

۲. فایل‌های در محدوده را تغییر دهید. برای منطق رفتاری آزمون معنادار اضافه کنید و راهنمای انگلیسی و فارسی را هماهنگ نگه دارید.

۳. از ریشهٔ مخزن بررسی‌ها را اجرا کنید:

</div>

```sh
python3 .github/scripts/test.py
bash -n tools/cx
shellcheck --severity=error tools/cx
claude plugin validate .
for mod in project-status session-chat agent-board prompt-router; do
  claude plugin validate "$mod"
  claude plugin test "$mod"
done
```

<div dir="rtl">

اجرای مستقل به Bun و Python 3 نیاز دارد و در پوشهٔ موقت فقط واردکردن کیت آزمون را به bun:test نگاشت می‌کند؛ اتصال هوک و رابط کاربری را پوشش نمی‌دهد. آزمون اضافی، اسکنر Python لاگ Codex را با دادهٔ ساختگی اجرا می‌کند.

دو شکست موجود در آزمون‌های session-chat و prompt-router باید شفاف گزارش شوند؛ آن‌ها را skip نکنید. اجرای بومی در محیط بررسی‌شده بدون گزارش فایل پایان یافت و باید در میزبان سازگار دوباره بررسی شود. تغییر رفتار رابط کاربری نیازمند بررسی دستی با claude --plugin-dir است.

۴. درخواست ادغام باید مسئله، تغییر، فایل‌ها و نتیجهٔ دقیق بررسی‌ها را داشته باشد. پیش از انتشار یا پوش، بازبینی نگه‌دارنده لازم است. مسیرهای نصب، مدل‌ها و قابلیت‌های اعلام‌شده را با سورس تطبیق دهید؛ ادعای آزمون موفق بدون اجرا نکنید.

آسیب‌پذیری را در issue عمومی مطرح نکنید؛ از [گزارش خصوصی GitHub](https://github.com/66Hamidreza/claude-code-mods/security/advisories/new) استفاده کنید. [راهنمای انگلیسی مشارکت](../../CONTRIBUTING.md) و [آیین رفتار](../../CODE_OF_CONDUCT.md) نیز اعمال می‌شوند.
